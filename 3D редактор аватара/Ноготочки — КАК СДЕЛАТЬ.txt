ЧАСТЬ 1. КАКОЙ СПОСОБ ЛУЧШЕ — И ПОЧЕМУ
══════════════════════════════════════════════════════════════

Есть два пути:
  A) ГЕОМЕТРИЯ — смоделировать 3D-коготь и приклеить к кости кончика пальца.
     + Объёмные, красивые, двигаются вместе с пальцем, VRM их несёт.
     − Чуть дольше (≈40 мин в первый раз).

  B) ТЕКСТУРА — нарисовать ноготь прямо на PNG-текстуре кожи.
     + Быстро (≈10 мин), не нужно трогать скелет.
     − Плоские, не выступают, только «нарисованные».

Для кошкодевочки лучше PATH A (геометрия) — когти острые, 3D, двигаются.
Ниже — оба варианта.

ЧАСТЬ 2. ВАРИАНТ A — 3D-КОГТИ В BLENDER (РЕКОМЕНДУЕТСЯ)
══════════════════════════════════════════════════════════════

Инструмент: Blender 5.2
Файл: C:\Users\KOT\Desktop\3D редактор аватара\Для Blender\Клава.blend

─────────────────────────────────────────────────────────────
ШАГ 1. Открыть Клаву в Blender
─────────────────────────────────────────────────────────────
  1. Запустить Blender 5.2 (C:\Program Files\Blender Foundation\Blender 5.2\blender.exe)
     или дважды щёлкнуть «Клава.blend» — откроется сразу.
  2. В сцене слева в Outliner (дерево объектов) видишь коллекцию «Клава».
     Раздел «Тело» → там объект «Тело · Bodybaked_...».
  3. Нажми пробел — проиграй анимацию (убедись, что пальцы двигаются).

─────────────────────────────────────────────────────────────
ШАГ 2. Создать заготовку когтя (один раз, потом копируем)
─────────────────────────────────────────────────────────────
  1. Нажми Shift+A → Mesh → Cone (конус).
     В левом нижнем углу появится панель «Add Cone» — измени там:
       Vertices: 6  (шестигранный — похоже на коготь)
       Radius 1: 0.003  (основание когтя, ≈3 мм)
       Radius 2: 0.0003 (острый кончик)
       Depth: 0.012     (длина 12 мм)
     Если панель закрылась — F9 вернёт её.

  2. Повернуть коготь:
     • Нажми R → X → 90 → Enter (положи острием вперёд).
     • Нажми R → Z → −5 → Enter (чуть наклони вниз, как настоящий коготь).

  3. Переименуй объект: щёлкни правой кнопкой по конусу → Rename → «Коготь_образец»

─────────────────────────────────────────────────────────────
ШАГ 3. Добавить материал когтю (цвет, блеск)
─────────────────────────────────────────────────────────────
  1. Выдели «Коготь_образец», перейди на вкладку Material Properties (иконка шарика).
  2. Нажми «+ New» (новый материал).
  3. Назови его «КогтиМатериал».
  4. Base Color → выбери тёмно-серый / чёрный (коготь кошки) или
     нежно-розовый (ноготочек аниме-девочки) — на вкус.
     Metallic: 0.3,  Roughness: 0.2  (лёгкий блеск).

─────────────────────────────────────────────────────────────
ШАГ 4. Присвоить весовые группы (Vertex Groups) — привязка к кости
─────────────────────────────────────────────────────────────
  Когти должны двигаться вместе с кончиками пальцев.
  Нужно: добавить объект как дочерний к скелету с Vertex Group по имени нужной кости.

  4а. Сначала приклей к нужной кости Parent:
      • Выдели «Коготь_образец» (ЛКМ).
      • Зажми Shift и нажми ЛКМ на «Скелет Клавы» в Outliner → теперь оба выделены,
        скелет — активный (оранжевый).
      • Ctrl+P → Bone (появится список костей) → выбери «J_Bip_R_Index3» (указательный правой руки).
      Коготь теперь дочерний к этой кости.

      АЛЬТЕРНАТИВА (если Ctrl+P → Bone не даёт список):
      • Перейди в Pose Mode на скелете (Tab пока скелет выделен → Pose Mode).
      • Выдели кость J_Bip_R_Index3 (клик по ней).
      • Вернись в Object Mode (Tab).
      • Выдели коготь, потом Shift+клик скелет → Ctrl+P → Bone.

─────────────────────────────────────────────────────────────
ШАГ 5. Позиционировать коготь на кончике пальца
─────────────────────────────────────────────────────────────
  1. Выдели коготь, нажми G (перемещение) и подгони к кончику пальца.
     Полезно: вид спереди Num1, вид сбоку Num3.
  2. Используй Pose Mode скелета: выдели скелет → Tab → согни пальцы → проверь,
     что коготь идёт вместе с пальцем.
  3. Отрегулируй масштаб S → X/Y/Z если надо.

─────────────────────────────────────────────────────────────
ШАГ 6. Скопировать на все 10 пальцев
─────────────────────────────────────────────────────────────
  Кости для привязки (из модели Клавы, проверено):
    Правая рука: J_Bip_R_Index3, J_Bip_R_Middle3, J_Bip_R_Ring3, J_Bip_R_Little3, J_Bip_R_Thumb3
    Левая рука:  J_Bip_L_Index3, J_Bip_L_Middle3, J_Bip_L_Ring3, J_Bip_L_Little3, J_Bip_L_Thumb3

  Для каждого пальца:
  1. Выдели «Коготь_образец» → Shift+D → Enter (дубликат на месте).
  2. Переименуй (правый клик → Rename): «Коготь_R_Middle», «Коготь_R_Ring» и т.д.
  3. Ctrl+P → Bone → выбери нужную кость.
  4. Подвинь G точно на кончик.

  Большой палец: коготь чуть меньше (S → 0.8 → Enter) и другой угол (R → Z → 30).

─────────────────────────────────────────────────────────────
ШАГ 7. Положить все когти в коллекцию «Тело»
─────────────────────────────────────────────────────────────
  Выдели все когти (клик по одному → Shift+клик по остальным в Outliner).
  В Outliner: M → выбери коллекцию «Тело» (или «Прочее» → потом перетащи).
  Это нужно, чтобы скрипт пересборки не запутался.

─────────────────────────────────────────────────────────────
ШАГ 8. Сохранить и экспортировать в VRM
─────────────────────────────────────────────────────────────
  Сохранить: Ctrl+S (сохранит в Клава.blend).

  Экспорт в VRM (аддон уже установлен — VRM format 4.7.2):
  1. Выдели «Скелет Клавы» в Outliner.
  2. В боковой панели справа (N) появится вкладка «VRM».
  3. VRM → Humanoid → нажми «Automatic Bone Assignment»
     (аддон сам сопоставит J_Bip_… кости стандарту VRM).
  4. File → Export → VRM (*.vrm)
  5. Сохрани как «Клава_с_когтями.vrm» в папку:
     C:\Users\KOT\Desktop\3D редактор аватара\Модель\

─────────────────────────────────────────────────────────────
ШАГ 9. Применить к Клаве
─────────────────────────────────────────────────────────────
  1. Открыть «Редактор Клавы» (ярлык на рабочем столе, лнк-файл).
  2. Кнопка «Сменить модель…» → выбери «Клава_с_когтями.vrm».
  3. В разделе «Части» убери галочку с дублирующихся когтей (если они вдруг появятся от оригинала).
  4. «Сохранить в Клаву» (Ctrl+S) — живая Клава перерисуется.

ЧАСТЬ 3. ВАРИАНТ B — НАРИСОВАТЬ НОГТИ НА ТЕКСТУРЕ (быстро)
══════════════════════════════════════════════════════════════

Инструмент: Blender 5.2 → Texture Paint  ИЛИ  любой растровый редактор.
Текстура кожи: C:\Users\KOT\Desktop\3D редактор аватара\Текстуры\F00_002_02_Body_00_SKIN.png

ВАЗ B1: Нарисовать в Blender (Texture Paint)
─────────────────────────────────────────────
  1. Открыть «Клава.blend».
  2. В Outliner выдели объект «Тело · Bodybaked_...».
  3. Вверху Mode Selector (где написано «Object Mode») → выбери «Texture Paint».
  4. В 3D-вьюпорте появится кисть. Справа: Tool → Brush → выбери цвет ногтя.
  5. Покрась кончики пальцев прямо на 3D-модели.
  6. Image → Save All Images (сохранит PNG на диске).

ВАЗ B2: Нарисовать в GIMP / Paint.NET / Photoshop
──────────────────────────────────────────────────
  1. Открой «F00_002_02_Body_00_SKIN.png».
  2. Найди развёртку пальцев (тонкие полоски сверху текстуры — это пальчики VRoid).
  3. Нарисуй полукруглый ноготь у кончика каждого пальца.
     Цвет: нежно-розовый (#FFAAB0) с лёгким светлым бликом.
  4. Сохрани под тем же именем.
  5. В Редакторе Клавы: вкладка «Кисть» → кнопка «Своя…» → выбери свой PNG.

  Чтобы точно попасть на пальцы: в Blender → UV Editor (сверху вкладка) →
  выдели объект «Тело» → вкладка «UV Editing» → видно, где именно пальцы на текстуре.

ЧАСТЬ 4. СОВЕТЫ ПО ФОРМЕ КОГТЕЙ
══════════════════════════════════════════════════════════════

  Аниме-ноготочки (нежные):
    • Конус: Radius1=0.004, Radius2=0.001, Depth=0.008, Vertices=8
    • Цвет: нежно-розовый, Metallic=0.1, Roughness=0.3
    • Угол наклона: R→X→85 (почти вертикально)

  Кошачьи когти (острые):
    • Конус: Radius1=0.003, Radius2=0.0001, Depth=0.015, Vertices=6
    • Дополнительно: Edit Mode → выдели все вершины → S→Y→0.5 (сплюснуть в серп)
    • Цвет: тёмно-серый / полупрозрачный (#C8B8A8)
    • Loop Cut (Ctrl+R) посередине → сдвинь вверх → получится загнутый коготь

  Накладные ногти (острые цветные):
    • Конус: Depth=0.01, потом в Edit Mode придай форму трапеции (G+Z вершинам основания)
    • Любой яркий цвет: красный, чёрный, голографический (Metallic=0.9, Roughness=0.05)
