КЛАВА В BLENDER (5.2)
=====================

Открыть: двойной клик по «Клава.blend».

Как устроено
  Коллекция «Клава»:
    Лицо и глаза, Волосы, Тело, Кимоно, Уши, Хвост — каждая часть отдельным объектом.
    Мех (слои)   — слои меха ушей и хвоста (из полусотни оставлен каждый четвёртый — работать удобно).
    Спрятанное   — куски, которые у Клавы выключены (родной костюм Виты, её кибер-ушки).
                   Включи глаз — наденется.
    Скелет       — «Скелет Клавы» (кости VRoid: J_Bip_…; у хвоста своя цепочка костей).
  Формы лица (улыбка, моргание, «а-о-у»…) — в свойствах объекта «Лицо · …» → Data → Shape Keys.
  Кимоно — обычная картинка (узор запечён редактором), её можно дорисовывать в Texture Paint.
  Поза — Pose Mode на скелете. Хвост и уши двигаются своими костями.

Снять/надеть: глаз у объекта или у коллекции. Перекрасить/дорисовать: вкладка Texture Paint.
Картинки упакованы внутрь .blend — файл можно носить одним куском (File → External Data → Unpack, если
нужно достать PNG).

Обратно в Клаву (в VRM)
  Клава грузит только VRM. Для экспорта VRM нужен бесплатный аддон «VRM format» (saturday06):
  Edit → Preferences → Get Extensions → поиск «VRM» → Install.
  Потом: выдели скелет → вкладка VRM → Humanoid → «Automatic Bone Assignment» (кости VRoid он узнаёт сам)
  → File → Export → VRM. Готовую VRM — в Редактор Клавы: «Сменить модель…». Кимоно, ушки и хвост
  тогда уже есть в самой модели — сними их галочками в редакторе («Части»), чтобы не надеть второй раз.
  Проще путь для VRM: импортировать в Blender сразу «Модель\Клава — база (Vita, CC0).vrm» через этот аддон.

Пересобрать .blend после новых правок в редакторе:
  1) Редактор Клавы → «Экспорт для Blender»;  2) двойной клик «Пересобрать Клава.blend.bat».
  Внимание: пересборка перезаписывает Клава.blend — свои правки в Blender сохраняй под другим именем.
