## 2. Архитектура Арены

### А. Бэкенд: `H:\Neiro\Neko\gamer\arena\server.py`
- **Протокол (TCP `127.0.0.1:47310`)**:
  - Клиент (KlavaDesk) шлет заголовок `[u32 LE json_len][u32 LE big_jpeg_len][u32 LE small_jpeg_len]`.
  - JSON мета: `{"t": ms, "user": false, "event": null, "hold": false}`.
  - Большой JPEG 640×360 — для глаз (YOLO11n-pose).
  - Маленький JPEG 256×144 — для ног (нейронка движения).
  - Ответ: JSON-строка `{"keys": [...], "dx": .., "dy": .., "lmb": 0|1, "rmb": 0, "why": "...", "targets": n, "gain": ..}\n`.
  - Пакет с `json_len == 0` — сброс раунда/карты (забывание целей).
- **Зрение (YOLO11n-pose)**:
  - Ищет людей и ключевые точки лица (нос, глаза, уши) -> точные координаты головы.
  - Защита от самонаведения: оружие и руки Клавы внизу экрана отфильтровываются.
  - Работает на **CUDA FP16** с прогревом при старте.
- **Человеческий прицел (Aim)**:
  - Гистерезис цели: не прыгает между врагами, держит фокус.
  - Человеческая задержка реакции: `160–260 мс`.
  - Ограничение угловой скорости (`1500 px/s`) и микро-дрожь руки.
  - Стрельба очередями (длина очереди зависит от дистанции, между очередями пауза для сброса отдачи).
  - Анти-отдача: компенсация прицела тягой вниз во время стрельбы (`my += 1.4 * dt * 60`).
  - Приседание (`CTRL`) при перестрелке вблизи.
- **Ноги (Legs)**:
  - Если есть выученная модель `policy.pt` в `gamer\models\<игра>` — двигается по записям друга.
  - Если нет — автономный разведчик `scout`: стрейфы в бою, движение вперед с обходом углов и разворотом при упоре в стену.

### Б. C# Клиент: `H:\Neiro\Neko\app\KlavaDesk\ArenaPlayer.cs`
Построен строго по эталону `GamePlayer.cs`:
1. Автоматически стартует `server.py` через `gamer\.venv\Scripts\python.exe` с аргументами `--game <игра> --detector <yolo.pt> --port 47310`.
2. Ждет сигнал `READY` от сервера (с таймаутом).
3. Грабит клиентскую часть окна игры 30 раз в секунду (`ClientOnScreen`), закрашивает окна Клавы черным (`KlavaWindows`) и жмет в два потока JPEG: 640×360 и 256×144.
4. Отправляет кадры и исполняет ответ сервера честными лапками:
   - Клавиши: через `paws.PadDown` / `paws.PadUp` со сканкодами DirectInput.
   - Мышь: относительный `Native.SendInput` с флагом `MOUSEEVENTF_MOVE` (кушается играми через Raw Input).
   - Огонь: зажатие ЛКМ через `paws.PadMouseDown(MouseButtons.Left)`.
5. **Безопасность**:
   - Окно игры не в фокусе -> мгновенная пауза и отпускание всех клавиш.
   - Друг нажал `Backspace` или `Esc` -> мгновенная остановка и возврат контроля человеку.
   - Голосовая команда «стоп» -> мгновенная остановка.
6. **Аватар**:
   - При старте зовет `GameMode.Enter("arena")` -> Клава садится в кресло за стол с ноутом.
   - При завершении зовет `GameMode.Leave("arena")` -> встает.
