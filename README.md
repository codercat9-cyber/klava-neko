# Клава — ИИ-кошкодевочка на рабочем столе

Живой 3D-аватар (VRM) поверх всех окон, с которым разговариваешь голосом. Клава слышит и узнаёт друзей по голосу,
отвечает своим голосом, видит экран, работает на компьютере лапками (мышь, клавиатура, терминал, файлы, браузер,
Paint) и сама заводит разговор, когда долго тихо. Мозг — на выбор: облачный (DeepSeek, Gemini, Antigravity Tools,
Claude Code) или свой локальный (Qwen3.6-35B-A3B uncensored через llama.cpp).

Личный некоммерческий проект. Windows 10/11 x64.

## Что нового (18.11.2026) — что проверить

- **Мозг отвечает всегда — больше никакого «мозг не ответил»**. Раньше запасной был один: когда AG Tools упирался в
  лимит, а запасная Жминя по ключу была без квоты, Клава молчала. Теперь **цепочка**: выбранный мозг → у Antigravity
  сначала **соседние модели того же AG** (список живой, с сервера — новые модели вроде hydrogen/carbon подхватываются
  сами) → DeepSeek → Жминя → ChatGPT через Codex → свой локальный мозг последним. Кто на лимите, тот **отдыхает ровно
  столько, сколько сказал сервер** («cooldown 5300s», 429, 402 «нет денег») и не долбится по три раза; модель, которая
  промолчала дольше срока, полторы минуты идёт мимо. Отказали все — она **говорит, почему**: «Антигравити на лимите,
  Дипсик без денег, локалка лежит».
- **Упал прокси AG Tools посреди разговора** — Клава поднимает его сама (раньше только при старте и смене мозга),
  а пока он встаёт, отвечает запасной.
- **Почему AG писал «All accounts rate-limited» при 100 % квоты**: модели Claude 5.5 и Gemini 4 Argon/Hydrogen есть только
  на одном аккаунте из пяти — circuit breaker AG запирает их вместе с аккаунтом. Пульт показывает это (⚠ одна), а
  Клава в таком случае пересаживается на модель, что есть на всех аккаунтах.
- **ChatGPT через Codex** — новый мозг `codex` по подписке ChatGPT: нужен Codex для Windows или `npm i -g @openai/codex`
  и вход `codex login`. «Переключись на кодекс». ~3–6 с на фразу, без рук на компьютере. Модель — в подменю трея
  (список берётся у самого Codex: модель из `~/.codex/config.toml` и всё, что он видел у подписки).
- **STRATA** — свой движок Strata (Qwen3.8-Flash-Next, 512 экспертов, без цензуры) мозгом `strata`: профиль находится
  сам по `profile.json` движка рядом с моделью, запуск — его `START_STRATA_*.bat`. Переход «свой мозг → STRATA»
  сначала гасит свой llama-server (вместе они не влезают в 96 ГБ), порт ждёт до 150 с. В автоматические запасные
  STRATA и другие свои серверы моделей не попадают — 62 ГБ без спроса не поднимаются.
- **Claude Code без входа** в меню и панели не показывается — переключиться на него всё равно нельзя. Вошёл
  (`claude auth login`) — пункт появится сам при следующем открытии меню.
- Голос: при срыве тона посреди фразы остаток теперь начинается **с первого непроизнесённого слова** — прозвучавшее
  распознаёт слух (whisper) и выравнивает по тексту. Раньше место угадывалось по темпу, и на стыке слово повторялось.
- **Пульт Клавы** (`pult_bin\KlavaPult.exe`, ярлык «Пульт Клавы»): запуск/перезапуск/выключение, службы и ключи
  одним взглядом, мозги и квоты AG по аккаунтам, «проверить связь», команды текстом (режимы, характер, мозг, дела),
  сборка с проверками, журнал в реальном времени, пакет для GitHub и **пуш по токену**.
- **Пуш на GitHub по токену** — `tools\push_github.ps1` (кнопка в пульте): спросит токен скрытым вводом и имя или ссылку
  репозитория, сам создаст репозиторий, проверит пакет на ключи и личное, запушит. Токен нигде не сохраняется.
- Журнал больше не засоряется «ОШИБКА speaker.identify … слишком коротко» на «ага»/«да».

## Что нового (10.10.2026) — что проверить

- **«Кыс-кыс, Клава»** — заткнуть её на полуслове (и песню), вместе с очередью; 30 с потом сама не заговаривает.
  Работает и при «Не слышать себя из колонок». Можно и текстом.
- **Голос без «мужика»**: тон каждой фразы меряется до колонок; провалился ниже её голоса — фраза пересинтезируется.
  В `data\logs\python-server.log` у фраз теперь «тон N Гц».
- **Звук из колонок — не люди**: видео, игра и её собственный голос, услышанные микрофоном, больше не идут в разговор
  и память словами друзей (лог `klava.log`: «колонки: r …»).
- **Кто в комнате — строго**: сказали «Паши нет» — его голос игнорируется, пока не скажут «Паша пришёл» (прямо, без
  «когда/если»); по похожему голосу никто не «возвращается». Блогеры и герои видео в комнате не бывают. Сама она
  больше не спрашивает одно и то же после каждого перезапуска.
- **Видео вместе**: открыл ролик на YouTube/Twitch/Rutube/VK Видео — она смотрит с вами: видит кадры, слышит речь
  из видео, ведёт журнал «кто что сделал/сказал» и может пересказать и оценить. Комментирует редко.
- **Игры**: Бакшот — понимает, что ты проговариваешь вслух, не пропускает смерти; окно игры снимается без нагрузки
  (не тормозит игру).
- **Запуск без сбоев**: голос больше не стартует дважды и не убивается сторожем посреди загрузки; если голос или слух
  не поднялись, узнавание голосов всё равно включается с правильным порогом (раньше своих переставало узнавать).
  Логи сервисов дописываются, а не затираются при каждом старте.
- **Быстрее голос**: пока она говорит, «кыс-кыс» ищется распознаванием, только если в микрофоне есть что-то кроме её
  эха из колонок — видеокарта не отнимается у синтеза (фразы с проверкой шли медленнее реального времени). Первый звук
  раньше (~0,65 с), а эмоция, у которой адаптер раз за разом уводит тон вниз, на 15 минут говорит без адаптера.
- **Переткнул микрофон в другой порт** — Windows дописывает к имени номер («Микрофон (4- Usb Audio Device)»); Клава
  теперь узнаёт его и не уходит на системный по умолчанию (там бывает тишина — она «одна в хате болтала»).
- **Сборка**: `Klava.sln` для студии и `СОБРАТЬ_КЛАВУ.bat` — см. «Сборка из исходников».

## Быстрый старт

Нужна Windows 10 версии 2004 (сборка 19041) или новее либо Windows 11, x64. Всё остальное скрипт поставит сам.

1. Распакуй архив `Klava-update-ДАТА.zip` (или `git clone`) куда угодно и запусти **`УСТАНОВИТЬ.bat`**. Он:
   - поставит, чего нет: .NET 9 SDK, WebView2 (на Windows 10 его бывает нет), Visual C++ 2015–2022, русское
     распознавание текста Windows (для игр; спросит права администратора). Есть winget — через него, нет (старая
     Windows 10) — официальными установщиками напрямую;
   - соберёт Клаву (`bin\KlavaDesk.exe`) и редактор аватара;
   - скачает лёгкий слух и голос (~350 МБ, работают на процессоре) и векторы памяти bge-m3 (~0,6 ГБ);
   - положит блокноты игр (DOOM 3, Бакшот) и скачает песню для Карамельдансена (archive.org);
   - по желанию — свой локальный мозг, большой голос с эмоциями (видеокарта NVIDIA от 8 ГБ), Blender для мастерской;
   - спросит ключи облачных мозгов и положит их в переменные окружения пользователя (не в файлы);
   - сделает ярлыки «Клава» и «Пульт Клавы» на рабочем столе.
2. Запуск — ярлык «Клава», `START_KLAVA.bat` или кнопка «Запустить» в пульте.
3. Просто говори. Правый Ctrl — рация (перебить её), **Ctrl+Alt+M** — написать текстом. Всё остальное — правый клик по Клаве.

## Обновление

1. Распакуй новый архив в **отдельную** папку (не поверх старой Клавы) — или `git pull`, если ставил через git.
2. Запусти в ней **`ОБНОВИТЬ.bat`**. Он сам:
   - найдёт установленную Клаву (по ярлыку «Клава», запущенной Клаве или папке рядом; не нашёл — спросит путь);
   - закроет её (память записывается), перенесёт новый код и уберёт файлы, которых в новой версии больше нет;
   - доставит новые зависимости и модели, пересоберёт и запустит.
3. Папку с новой версией после этого можно удалить.

Личное не трогается: память и журналы (`data`), голосовые профили друзей, модели, свой мозг и большой голос,
`klava.json`, её вещи и наряды (`web\config.json` — новые дефолты из `web\config.default.json` доезжают, свои правки
остаются, прошлый файл — в `web\config.backups`).

Автору: `СОБРАТЬ_АРХИВ_ДРУЗЬЯМ.bat` в папке Klava-GitHub — свежая копия проекта и архив рядом с ней;
`ОТПРАВИТЬ_НА_GITHUB.bat` — то же в приватный репозиторий.

## Что умеет

| | |
|---|---|
| **Разговор** | Живая речь по-русски, характер в `persona.txt` (душа поэтессы, художницы, музыкантки и геймерши, немного классической женщины), режимы «обычная / без мата / умеренная / рассудительная / рейдж» — меняется только мат, живость остаётся. Отвечает фразами по мере генерации; голос идёт потоком — первый звук через ~0,7 с после первой фразы мозга, без «хм…» и заглушек. **Кто рядом** — по факту, а не по списку: рядом те, чей голос слышен за последние 25 минут, к остальным она не обращается; у события без голоса (погладили, вернулись к компьютеру) имя не выдумывает. **Честность:** сказала «запускаю» без инструмента — делает или прямо говорит, что не хочет; на реплику нескольких человек сразу инструменты есть так же, как на одиночную. |
| **Память** | Всё на одной оси времени. **Журнал** (`data\journal\ДАТА.jsonl` + `.md` по часам) только дописывается: каждая реплика с видом и точным временем, слова людей один раз, фон отдельно. **Часы**: в каждой реплике мозг знает число, день недели и время, после запуска — сколько спала, после паузы — сколько молчали; в истории разговора у реплик стоит время. **Банк** (эпизоды со временем с–по, планы, заметки): на вопрос про прошлое («вчера вечером», «в три часа», «час назад», «в пятницу», «28.09») — хроника именно этого отрезка, на длинный день — оглавление по часам, на узкий отрезок — реплики дословно. **Граф фактов**: сущности со склонениями зажигают подграф, он гаснет за ~6 реплик, заезженное штрафуется; каждый факт — с датой. Всё к слову подмешивается одним списком от давнего к свежему. Имена людей — в одном виде (прозвища, склонения, ослышки → имя профиля). Свои обещания («передай им…») она помнит и выполняет сама. Запись памяти — целиком или никак, с `.bak` и копиями дня; что уже вспоминала и когда выключалась, переживает перезапуск. Векторы — bge-m3 на процессоре, ~0,1 с на реплику; раз в сутки «сон»: дубли сливаются, забытое уходит в архив. |
| **Облик** | Моргает по-живому (разгон, задержка, двойные, медленное кошачье), челюсть ходит вместе с ртом, левый глаз — киберимплант с живой подсветкой, клычок, родинка. **Гардероб**: кимоно, готика, киберпанк, классическое платье, родной киберкостюм — переодевается сама (метка `[наряд …]`) со вспышкой. **Зеркало**: «как ты выглядишь?» — видит свой снимок. |
| **Мастерская** | 3D-вещи делает себе сама (инструмент `craft`): наушники, очки, рожки, крылья, меч в лапу, ваза на пол — из простых форм (шар, коробка, цилиндр, тор, тело вращения, трубка, выдавленный контур) с материалами и зеркальной парой, в своих координатах (влево — вверх — вперёд от точки крепления), на любой кости или на полу. Получает снимок вещи с четырёх сторон и поправляет. Сложное — своим скриптом Blender (`bpy` → `.glb`), готовую модель `.glb` — импортом, свою вещь — файлом на рабочий стол. Вещи остаются после перезапуска (`web\config.json` → `craft`). |
| **Шалости** | Чипсы, рыбка, чеснок (потом зелёный пар при разговоре), рыг посреди фразы как у Рика и пук — с зелёным облаком и живыми звуками (CC0, `web/voices/sfx`). |
| **Музыка** | Слышит музыку по-настоящему, а не «по ощущению»: трек раскладывается на дорожки (Demucs), доли и такты (beat_this), грув ударных (свинг, оттяжка малого в мс), ноты (RMVPE, Basic Pitch), аккорды и тональность, форму (куплет/припев), инструменты с вероятностями (AST), текст (whisper) и звук (LUFS, спектр) — паспорт трека уходит мозгу, и она судит по фактам, хоть Моцарта. «Послушай, что играет» — пишет звук компьютера без своего голоса и кивает в такт живому биту. **Поёт каверы своим голосом**: по-русски — сама переводит слог в слог под ноты оригинала (проверка слогов кодом), ACE-Step 1.5 поёт песню с этим текстом живым вокалом по смысловым кодам оригинала (форма, мелодия, тайминг), из нескольких вариантов судья выбирает лучший (разборчивость whisper'ом и попадание в мелодию), Seed-VC переводит голос в её тембр; без ACE — прежний путь (её речь, растянутая WORLD по нотам); или в оригинале. **Своя музыка**: сочиняет мелодию по настроению и играет за синтезатором, на скрипке — тему 24-го каприса Паганини. | **Обстановка и быт** | Её собственные хотелки из разговоров: мягкий коврик под лапки, дедовское кресло с салфеточкой и массажное, кровать с балдахином и пледом, ванна с пеной, микрофон на стойке, большие наушники, синтезатор (пальцы по нотам своей мелодии), скрипка со смычком, танцы под бит — метками [кресло] [кровать] [спать] [ванна] [танец] [встать] сама или по просьбе (трей → 🛋). Поёт в стойке Фредди Меркьюри — золотой микрофон на полустойке, кулак вверх на протяжных нотах. **Гардероб:** к нарядам своя обувь (берцы на шнуровке, лаковые сапоги с неоновым кантом, ботильоны), берет художника к кимоно, «готика с верёвочками»; вещи она делает себе сама — инструментом wardrobe шьёт свои наряды (основа, цвета, обувь, шляпа), правит волосы и кимоно, как в редакторе. Зеркало в три кадра — спереди, со спины (хвост) и лицо. Ночью, когда друга нет, спит в кровати и пишет дневник — мысли за день по памяти и сон; утром рассказывает сон (data\diary и «Дневник Клавы» на рабочем столе). |
| **Слух** | Без кнопки (детектор речи) или рацией. Узнаёт, кто говорит (голосовые профили), в режиме «соло / двое / трое» слушает только выбранных, телевизор и чужих пишет фоном. Своё эхо из колонок отсекает. Реплики друга, сказанные посреди её задачи, долетают сразу, а не после. |
| **Голос** | Большой — клон её эталона: Qwen3-TTS 1.7B с адаптером ударений (ударения ставит RUAccent + свой словарь `tts/custom_stress.json`, в модель уходит невидимый знак U+0301 — никаких «плюсов» вслух); лёгкий — Supertonic-3 на процессоре. Обрыв связи — фраза повторяется тем же голосом; лёгкий подменяет, только если `liteFallback` включён. Поток не рвётся, когда синтез медленнее звука (мозг и голос на одной видеокарте): фраза стартует с запасом по темпу прошлых фраз, а при провале страница копит кусок побольше — одна пауза вместо дрожи. |
| **Глаза** | Снимок экрана с сеткой координат + распознанный текст + кнопки активного окна; лупа по кусочку. **«Наблюдай»**: сама поглядывает на экран, ведёт журнал со снимками (что рисуют, кодят, смотрят) и по просьбе собирает отчёт — «что было, пока я спал». |
| **Лапки** | Терминал (живой PowerShell), файлы, программы, ярлыки, браузер и вкладки (текст страницы — как он нарисован, со скриптами), Google Переводчик и погода, клик по кнопкам по имени (UI Automation), печать. **Автопилот** (панель → «Автопилот»): делает всё сама — режутся только катастрофы (формат, разметка дисков, снос Windows), безвозвратное удаление уходит в Корзину; без автопилота опасное — с подтверждения. Ненулевой код выхода — повод разобраться, а не бросить. Дёрнул мышь или Esc — сразу отпускает. |
| **Агенты** | Работа дольше пары команд — её агентам: каждый — **Claude Code** (подписка, если CLI залогинен, иначе Anthropic-вход AG Tools) со своей вкладкой в кибер-терминале: терминалы, правка файлов, поиск, веб, скиллы и агенты из `~/.claude`, MCP друга (кроме голоса и мыши), дев-плагины (`agentPlugins`), **свои субагенты** для параллельных кусков, план. Разрешения спрашивает у Клавы (автопилот — сама, опасное без автопилота — окном). Несколько агентов сразу (`agentMaxParallel`); Клава видит шаги, план и субагентов каждого, подправляет по ходу, останавливает (голосом — «стоп агент»). **Модель — на ходу**: «переключи агента на джемини 3.8 флеш хай / 3.1 про / опус 4.6 синкинг» или кнопка 🧠 во вкладке — агент пересаживается на любую модель шлюза и продолжает с того же места; упёрся в лимит (503, «accounts limited») — сам идёт по цепочке запасных (`agentModel` → `agentFallbackModel` → `agentModels`). **Мультитерминал**: вкладка Клавы, ⌨ ➕ PS — ещё живые PowerShell для тебя, 🤖 ➕ Агент — задача агенту прямо из терминала. |
| **Игры** | Игровые руки: клавиши сканкодами (их видят и старые игры), несколько сразу, поворот камеры мышью, серии ходов со снимком окна игры после каждого. **Тетрис** — свой автопилот (Jstris, эвристика El-Tetris), играет сам, пока ты болтаешь. **Minecraft** — заходит отдельным игроком (mineflayer): сама находит мир, открытый «для сети», ходит, добывает, дерётся, отвечает в чат игры. |
| **Paint** | Рисует по холсту в своих координатах: точные фигуры (пиксель в пиксель, цвет можно взять с холста), живые мазки любой кистью Paint (акварель, масло, маркер…) точным цветом #RRGGBB и с прозрачностью, заливка, текст. **Слои**: создать, выбрать, скрыть, выше/ниже, копия, слить, удалить — прозрачное на слое остаётся прозрачным. Сама проверяет результат по снимку с сеткой и лупой. Картины подписывает **от руки** — каллиграфической кистью, штрих за штрихом (имя, росчерк, лапка), никогда не текстом. Новая картина — в своём окне Paint на чистом холсте формата образца или просьбы («вертикальный», «квадрат», «широкий»), файл в «Картины Клавы»; фигура целиком в кадре; живопись до мелкой кисти с лессировкой — без «раскраски по номерам»; «готово» — только когда легло всё и холст сверен с образцом. |
| **Живость** | Сама заводит разговор, когда тихо, радуется, когда вернулся, ночью гонит спать, через два часа за компом зовёт размяться. Жесты: пиво, сигаретка, ня, рукалицо; когда печатает — достаёт ноутбук. |
| **Мозги** | Меню «Мозг» или голосом «переключись на дипсик». Запасной мозг подхватывает, если основной молчит. Честность: провал инструмента помечается, «сделала» без действия — пинок вызвать по-настоящему. Свой мозг в болтовне идёт с DRY-штрафом за повтор собственных фраз из истории (иначе залипает на одной выкройке ответа). Поиск в интернете (`web_search`, `web_fetch`) — в фоне и без спроса: ни окон, ни табличек; адреса своей сети — по-прежнему с разрешением. |

## Слух и голос: два комплекта

| | Лёгкий (`lite`) | Большой (`full`) |
|---|---|---|
| Где считается | процессор, 2–4 ядра | видеокарта NVIDIA от 8 ГБ |
| Слух | GigaAM v3 + Silero VAD | whisper large-v3-turbo |
| Голос | Supertonic-3 (голос F2, чуть выше) | Qwen3-TTS 1.7B + адаптер ударений — клон её эталона (видеокарта < 7 ГБ — 0.6B без адаптера) |
| Кто говорит | ERes2Net (3D-Speaker) | WavLM base plus sv |
| Нужно | ~350 МБ моделей, ~0,8 ГБ ОЗУ, без Python | ~7 ГБ моделей + Python-окружение ~6 ГБ, ~4,5 ГБ видеопамяти |
| Установка | `tools\fetch_lite.ps1` (делает УСТАНОВИТЬ.bat) | `tools\setup_full.ps1` |

`speechBackend` в `klava.json`: `auto` (по умолчанию — большой, если установлен, иначе лёгкий), `full`, `lite`.
Переключается и в окне «Настройки микрофона и слуха».

Мозги, модели, прокси — в `klava.json` (создаётся при первом запуске) и в окне «Настройки мозгов».

**Цепочка запасных** (`Brain.FallbackChain`, `BrainGuard.cs`): выбранный → ссылки `fallback` профилей → остальные
API-мозги → Codex → свой мозг (если модель на диске). Мозг без ключа или без входа пропускается. У профилей со списком
моделей с сервера (AG Tools) на лимите/пропаже модели сначала пересадка на соседнюю: живые модели с `/models`, по
покрытию квотой из `~/.antigravity_tools/accounts` (сначала те, что есть на двух и больше аккаунтах). Что отдыхает и
почему — в `data\logs\klava.log` строками «сторож мозгов: …».
Прокси для облака находится сам (`netProxy: auto`: переменные окружения, системный, порты Karing/Clash/v2ray).

## Сборка из исходников

Решение — `Klava.sln` в корне (KlavaDesk, редактор аватара, пульт). Открывается в Visual Studio 2022 (17.12+), Rider или
VS Code с C# Dev Kit; из консоли — `dotnet build Klava.sln -c Release`. SDK — .NET 9: `global.json` берёт самый
новый стабильный 9.0.x, превью 10 не трогает. Пакеты NuGet и их версии — одни на оба приложения:
`app/Directory.Packages.props`; общие настройки — `app/Directory.Build.props`, раскладка сборки —
`app/Directory.Build.targets`. Зависимости вне NuGet (голос, слух, модели, мозг) ставит `УСТАНОВИТЬ.bat`.

- **`СОБРАТЬ_КЛАВУ.bat`** — двойной клик: закрывает запущенную Клаву по-хорошему (память записывается), собирает
  Release, выкладывает в `bin`, `editor_bin` и `pult_bin` и запускает снова. Не собралось — `bin` не тронут, запускается прежняя.
  `powershell -File tools\build.ps1 -Test` — ещё и самопроверки; `-Debug` — отладочная сборка; `-NoStart`, `-Start`.
- **Release** собирается в `app\*\bin\Release\…` и сам выкладывается в `bin` / `editor_bin` / `pult_bin`, если оттуда ничего не
  запущено. Клава запущена — сборка успешна, но `bin` не трогается (предупреждение в выводе): так её агенты могут
  проверять свои правки сборкой при живой Клаве. `-p:KlavaDeploy=false` — не выкладывать; сборка с `-o` не выкладывает.
- **Debug** (F5 в студии) — `app\KlavaDesk\bin\Debug\…`, живую Клаву не трогает; папку Клавы находит по `klava.json`
  выше по дереву. Вторая копия при живой Клаве не запустится (одна Клава на машину) — сначала закрой её.

Личное в репозиторий не попадает: `data/` (история, журналы, записи голосов), `klava.json`, модели.
