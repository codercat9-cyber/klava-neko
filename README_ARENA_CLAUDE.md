## Меню и закуп — решение (честные клавиши, без консоли)

CS у вас на русском. Кадры: `data\watch\2026-09-28\051440.jpg` (закуп), `data\watch\2026-09-27\071711.jpg` (MOTD).

- **Закуп** в начале раунда (событие `round_start` из `CsBridge`): `B`, пауза, потом `A` — «АВТОМАТИЧЕСКАЯ ПОКУПКА», игра сама берёт броню, ствол и патроны. Если меню «Меню покупки» ещё на экране (OCR) — `0` (отмена). `,` и `.` (патроны) — одиночные нажатия, если патронов мало.
- **MOTD:** `Enter`; если не закрылся — щелчок по «OK» (координаты по OCR).
- **Команда и модель:** OCR видит «ТЕРРОРИСТЫ / СПЕЦНАЗ / АВТОВЫБОР» — жмёт `5` (или `1`/`2` по просьбе друга).
- **Смерть:** `CsBridge` даёт `host_dead` и `round_start`. До нового раунда клиент ничего не жмёт.

## Ноги

Разведчик в сервере: идёт вперёд, водит взглядом, упёрлась — разворот и прыжок, в бою стрейфится, перед очередью встаёт. Выученная нейронка теперь будет:
- давать движение с порогом 0,3;
- включать разведчика, если сама 1,5 с не жмёт движение;
- отдавать ногам только W/A/S/D/SPACE/CTRL/SHIFT.

При переобучении убрать из движения `B`, `,`, `.`: закуп — отдельный навык.

## Учёба на игре друга (DAgger)

Схема:
1. Друг посреди её игры берёт клаву или мышь: живой ввод по Raw Input, её SendInput туда не попадает.
2. Клиент отпускает всё, шлёт `user=true`, сервер отвечает `yield`.
3. Кадры и действия друга пишутся через каждый второй кадр (≈15/с, как в записях) в `gamer\data\<игра>\<дата>\` тем же форматом `GameRecorder`.
4. Дальше обычный `gamer train`.

Для этого `GameRecorder.Session` и `KeyName` нужно сделать `internal`.
